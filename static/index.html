Under the hood

The model chooses.
The code enforces.

Pareil is an agent with guardrails. The LLM tidies merchant names and decides how to recover when matches are thin. Plain, tested code ranks every swap and checks every claim.

  • Every place shown comes from Qloo — invented names are rejected.
  • Savings come from your own spending, and are labelled as estimates.
  • Every Qloo call is listed in a “How we know” panel.
